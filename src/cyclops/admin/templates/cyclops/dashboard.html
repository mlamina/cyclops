{% comment %} The admin interface's markup. The look is in admin/static/*.css and the behaviour in admin/static/*.js; what is left here is the shape of the document and the four places the server has something to say about it. Nothing is bundled, minified or built - the files are served as they are written (views.static_file), because the panel has no internet and this repo has no node. Laid out for the Pi's 800x480 panel first. It wears the same green terminal chrome as the kiosk overlay it opens from - same phosphor palette, same bezel, same monospaced readouts - because on the panel it is not a different application, it is the next screen of the same one. Every other device on the LAN gets the same document with lan.css on top of it. The volume bar, the two switches and the close bar exist only for the kiosk's own browser: a laptop on the LAN has nothing to close, everything else here is a read-only copy of what is on the card, and the panel is meant to be the one place the box is set - a slider and a switch on every device on the network is exactly the sprawl this replaced. The navigation forks on the same flag, and it is the one fork that is about the screen rather than about what the client is allowed to do: the panel is a known 800x480 that can hold four tabs, and a phone is not, so everywhere else the four screens are one menu instead. {% endcomment %} {% if local %} {% else %} {% endif %} Cyclops · status
